
# Task Tracker

A simple Java console application built to practice object-oriented programming and core Java concepts.

Task Tracker allows users to create, manage, and organize daily tasks directly from the terminal. It supports adding new tasks, viewing their status, marking them as completed, and deleting tasks that are no longer needed.

---

## About the Project

This project was developed as an academic mini project to strengthen my understanding of Java fundamentals.

While the application is simple, it covers many important programming concepts such as:

- Classes and Objects
- ArrayList
- Encapsulation
- Loops and Conditional Statements
- User Input with Scanner
- Menu-Driven Programs

The goal was to build a practical application that solves a real problem while applying core Java concepts.

---

## ✨ Features

### ➕ Add Task
Create a new task with:
- Title
- Description

### 📋 View Tasks
Display all tasks along with:
- Task ID
- Title
- Description
- Completion Status

### ✅ Complete Task
Mark any existing task as completed.

### 🗑️ Delete Task
Remove tasks from the tracker.

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/task-tracker.git
```

2. Navigate to the project folder.

```bash
cd task-tracker
```

3. Compile the files.

```bash
javac *.java
```

4. Run the application.

```bash
java Main
```
